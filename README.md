# Sublime Ecommerce

First functional version of a demo storefront for custom stickers, sublimated T-shirts, DTF and vinyl in Argentina.

## Requirements
Node.js 24+ and npm 11+.

## Local development
```powershell
npm.cmd install
npm.cmd run dev
```
Open http://localhost:3000.

## Quality
```powershell
npm.cmd run lint
npm.cmd test
npm.cmd run build
```

`npm.cmd test` runs the domain unit tests (catalog filters, cart, quote validation, price format) with Node's built-in test runner; no extra dependencies.

## Brand system
Implemented from the client's branding kit:
- Colors: black `#000000` (backgrounds, header, dark panels), white `#FFFFFF` (text on dark, light cards) and cyan `#35BDF2` (main buttons, links, active states, indicators). Cyan is never used as text on light surfaces (insufficient contrast); there it becomes a fill or underline marker.
- Typography: Bebas Neue (primary: titles, highlighted numbers, promotional buttons) via `next/font/google`, and Gontserrat (secondary: product names, prices, forms) self-hosted from `src/fonts/gontserrat` (OFL; latin WOFF2 subsets of the kit's TTFs).
- Logo: `public/brand/sublime-logo.png`, also used for the app icons.
- T-shirt photo mockups from the kit live in `scripts/art/assets` and are composited with prints by `npm.cmd run art`.
- Not used: "Bebas Notes" (no license information in the kit) and "Stay With Me" (personal-use license only; commercial use requires a paid license).

## Demo catalog and images
- Catalog data lives in `src/data/` (`products.ts`, `categories.ts`, `site.ts`), separate from UI components so it can later be replaced by a database.
- Product, category and editorial images are original SVG mockups in `public/demo/`, generated by `npm.cmd run art` (`scripts/generate-art.mjs`). Re-run it after editing motifs or scenes in `scripts/art/`.

The catalog, prices, cart and budget controls are intentionally demonstrative. No payment, database, authentication or real commercial flow is implemented.

See `docs/architecture.md` and `docs/roadmap.md` for decisions and next steps.
